📥 Import (CSV ou Excel)

Formats acceptés : CSV, Excel (.xlsx, .xls). Le fichier doit avoir exactement les mêmes colonnes que l'export CSV.

⚠️ L'import peut écraser tes données. Avec « Remplacer entièrement », toutes tes transactions actuelles sont supprimées puis remplacées par le contenu du fichier. Fais d'abord un export CSV si tu veux une sauvegarde.

Une fois le fichier envoyé, choisis l'option ci-dessous puis appuie sur le bouton « OK » qui apparaît juste en dessous.

Réglages

La connexion Supabase et l'adresse du script Google des cours se règlent maintenant dans l'onglet Général (⚙️ Réglages), une seule fois pour tout le patrimoine.

Exports et import : bouton « 📦 Exports / Imports ».
